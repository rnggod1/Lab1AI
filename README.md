# Лабораторная работа №1. Генетические алгоритмы

**Вариант 3.** Лучший по характеристикам рацион из k наименований,
удовлетворяющий заданным ценовым рамкам. Лучшим считается рацион
с минимальным отклонением от нормы.

## Структура

| Файл | Назначение |
|---|---|
| `data.py` | Продукты (цена + БЖУ + ккал на 100 г), целевые нормы, ценовые рамки, параметры ГА |
| `ga.py`   | Логика ГА и полный перебор |
| `main.py` | Точка входа: полный перебор + эксперименты ГА + графики |

### Содержимое `ga.py`

| Класс | Назначение |
|---|---|
| `DietProblem` | Ядро задачи: numpy-массивы цен и нутриентов, `decode()` |
| `Chromosome` | Хромосома (граммовки) + ремонт до ровно `k` ненулевых генов |
| `FitnessFunction` | Приспособленность `1 / (deviation + penalty + eps)` |
| `SelectionOperator` | Турнирная селекция |
| `CrossoverOperator` | 3 стратегии: uniform, single-point, arithmetic |
| `MutationOperator` | 3 стратегии: gauss, swap, reset |
| `GeneticAlgorithm` | Основной цикл с элитизмом |
| `BruteForceSolver` | Полный перебор (с параметром `step_override`) |
| `ExperimentRunner` | Прогон всех комбинаций операторов + графики |

## Контрольные вопросы
1. Структура хромосомы. Вектор длины N целых чисел; gene[i] —
количество граммов продукта i (0…500, шаг 10). Ровно k ненулевых генов.
Ноль означает, что продукт не входит в рацион. Такая кодировка напрямую
описывает рацион и легко ремонтируется.

2. Функция приспособленности. fitness = 1 / (deviation + penalty + eps),
где deviation — сумма квадратов отклонений от целевых норм, penalty —
штраф за выход стоимости за ценовые рамки. Это прямо отражает условие
варианта (лучший = минимальное отклонение), а штраф не даёт решениям
вне ценовых рамок доминировать. Квадрат отклонения сглаживает ландшафт.

3. Кроссовер и мутация.

Кроссовер — оператор скрещивания двух родителей, создающий потомка
путём комбинирования их генов. Реализованы: однородный, одноточечный,
арифметический.

Мутация — случайное изменение генов потомка с заданной вероятностью.
Реализованы: гауссова (изменение граммовки), swap (замена продукта),
reset (сброс и добавление нового). Мутация поддерживает разнообразие
и предотвращает преждевременную сходимость.

## Вывод
Реализован генетический алгоритм для задачи составления лучшего по
характеристикам рациона из k продуктов в заданных ценовых рамках.
Код разбит на три файла: данные (data.py), логика ГА (ga.py), запуск
(main.py) — это упрощает модификацию данных без изменения алгоритма.
Использованы реальные данные о продуктах. Проведены эксперименты с тремя
кроссоверами и тремя мутациями, построены графики сходимости. Результаты
ГА сопоставлены с полным перебором на уменьшенной размерности: ГА находит
близкие к оптимальным решения за приемлемое время даже при больших N.
